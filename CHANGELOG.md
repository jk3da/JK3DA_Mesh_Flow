# Changelog — JK3DA MeshFlow

All notable changes are documented here.  
Versioning follows [Semantic Versioning](https://semver.org/).

---

## [0.1.0] — 2026-05-10

First public release of the modular version.

### Added
- **Circle** — fit selected vertices to a circle using algebraic least-squares; supports regular / irregular spacing, custom radius, influence blend
- **Relax** — smooth mesh topology while preserving overall shape; configurable iterations, influence, boundary preservation
- **Space** — distribute vertices evenly along an edge path; supports multiple chains
- **Straighten** — project vertices to a straight line; axis locking (X/Y/Z), pivot options (first / last / midpoint), optional even spacing
- Sidebar panel in 3D View (Edit Mode)
- Right-click context menu integration
- Preferences panel
